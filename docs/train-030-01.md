## Outstanding work

None in this repository after the npm read-back (plan section 14). One observation goes to Get Modular for the
resources README recipe, and the owner decides whether it becomes an issue: on macOS `process.kill(-pgid, signal)`
can return `EPERM` for a moment after the group leader exited, while the remaining members are zombies that init has
not reaped yet. The adapter accepts `EPERM` only after the leader exited.
